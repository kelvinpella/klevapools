## Agent skills

### Issue tracker

This repo tracks issues in **GitHub Issues** using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default five canonical triage roles: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses **single-context** domain documentation. See `docs/agents/domain.md`.
